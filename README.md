## About

<img align="right" width="150" src="https://raw.githubusercontent.com/KanadeK/robot-expressive-codex-pet/main/media/actions/waving.gif" alt="Animated robot waving hello" />

I'm **Mohammad Sadique**, an **Electrical Engineering student at Jamia Millia Islamia, New Delhi**.

I connect **system simulation with physical prototypes**—exploring electrical behavior, programming microcontrollers, integrating sensors, and making robots move with feedback.

- 🤖 **Robotics:** sensing, navigation, and motion control.
- ⚡ **Electrical systems:** circuits, power electronics, and simulation.
- 🔌 **Embedded systems:** firmware, microcontrollers, and sensor integration.
- 📊 **Intelligent monitoring:** measurements, data logging, and fault analysis.
- 🧠 **Currently exploring:** predictive maintenance using IoT and ML.

**My favorite part?** Seeing an idea survive its first real-world test.
